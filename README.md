# Smart City EV Charging Network Management System

## Project Description

The Smart City EV Charging Network Management System is a database-driven web application designed to manage electric vehicle (EV) charging activities efficiently. The system helps manage user registration, login, charging station information, charging slot bookings, and payment records.

The project uses a web-based interface to interact with users, a Node.js backend to process requests, and a MySQL database to store and manage information. Separate database tables are used to organize user details, charging stations, bookings, and payments.

The main objective of this project is to simplify EV charging management, organize data efficiently, and reduce manual work through a centralized database system.

## Key Features

- User registration and login
- Charging station information management
- Charging slot booking management
- Payment record management
- MySQL database integration

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Development Tools:** Visual Studio Code, MySQL Workbench

## Project Objective

To develop a database-driven web application that organizes EV users, charging stations, bookings, and payment records in a structured and efficient way.
